# Drop certain types of globals

Drop certain types of globals

## Usage

``` r
# S3 method for class 'Globals'
cleanup(globals, drop = c("missing", "base-packages", "nativesymbolinfo"), ...)
```

## Arguments

- globals:

  A Globals object.

- drop:

  A character vector specifying what type of globals to drop.

- ...:

  Not used
